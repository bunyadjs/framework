# Security policy

## Supported versions

Security fixes go to the latest beta release of every `@bunyad/*` package. Alpha releases are not supported.

## Reporting a vulnerability

Please do not open a public issue.

Use GitHub's private reporting: open the **Security** tab of [bunyadjs/framework](https://github.com/bunyadjs/framework/security/advisories/new) and choose **Report a vulnerability**. Include the affected package and version, what an attacker can do, and steps or code to reproduce it.

You can expect an acknowledgement within a few days and a status update once the report is triaged. Fixes are released as patch versions, and the advisory credits the reporter unless you prefer otherwise.
