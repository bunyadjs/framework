# @bunyad/auth

Authentication for Bunyad: sessions, password, remember-me, email verification and bearer tokens.

> **Alpha.** APIs may change between `0.x` releases.

```bash
bun add @bunyad/auth@alpha
```

Requires Bun 1.1 or newer. Part of [Bunyad](https://github.com/bunyadjs/framework).
