# @bunyad/contracts

Interfaces and shared types for the [Bunyad](https://github.com/bunyadjs/framework) ecosystem (cache, filesystem, HTTP, mail, queue, session). Types only, no runtime logic.

> **Alpha.** APIs may change between `0.x` releases.

```bash
npm install @bunyad/contracts@alpha
```

You normally get this package as a dependency of other `@bunyad/*` packages.
