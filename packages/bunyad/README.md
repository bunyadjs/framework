# bunyad

The [Bunyad](https://github.com/bunyadjs/framework) command line. This package installs the same `bunyad` command as [`@bunyad/cli`](https://www.npmjs.com/package/@bunyad/cli).

> **Alpha.** APIs may change between `0.x` releases.

```bash
bun add -g bunyad
bunyad new
```

Or without installing: `bun create bunyad my-app`.

Requires [Bun](https://bun.sh) 1.1 or newer.
