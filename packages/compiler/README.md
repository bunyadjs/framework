# @bunyad/compiler

Build-time compiler for Bunyad: turns routes, views and the container into optimized JavaScript.

> **Alpha.** APIs may change between `0.x` releases.

```bash
bun add @bunyad/compiler@alpha
```

Requires Bun 1.1 or newer. Part of [Bunyad](https://github.com/bunyadjs/framework).
