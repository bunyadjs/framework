# @bunyad/notifications

Notifications for Bunyad: mail, database, Slack, SMS and broadcast channels.

> **Alpha.** APIs may change between `0.x` releases.

```bash
bun add @bunyad/notifications@alpha
```

Requires Bun 1.1 or newer. Part of [Bunyad](https://github.com/bunyadjs/framework).
